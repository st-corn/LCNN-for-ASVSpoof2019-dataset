# LCNN-for-ASVSpoof2019-dataset

В проекте реализована Light CNN для распознания сгенерированного или искусственно измененного голоса, используя для обучения и оценки датасет ASVSpoof2019.
В ноутбуке full_run_notebook находится полный запуск ноутбука. К сожалению, итоговый запуск, в котором EER на eval достиг 4.5412, не сохранился.
В ноутбуке pretty_version_with_comments находится версия с ноутбука с пояснительными комментариями, но без запуска.
